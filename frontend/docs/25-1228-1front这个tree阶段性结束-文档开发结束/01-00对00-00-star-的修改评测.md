### ⚠️ 有问题，但“不是删”，而是**要合并 / 改名**

#### 1️⃣ `a11y-reference-snippets.md` + `accessibility-examples.md`

**这是第一个明显错误。**

* 两个文件**语义高度重叠**
* 对 AI 来说：

  * `reference-snippets`
  * `examples`

  👉 **没有本质区别**

📌 **正确做法（必须改）**：

> **只保留一个：**

```
a11y-reference-snippets.md
```

* 内容：**模式级示例（pattern）**
* 不要再保留 `accessibility-examples.md`

否则 AI 会开始：

* 随机挑一个读
* 或把其中一个当“更高级版本”

这是非常典型的 **AI 语义分裂源头**。

---

#### 2️⃣ `animation-guidelines.md`

**问题不在内容，在“guidelines”这个词。**

在你这个仓库里：

* `guidelines`
  👉 **极容易被 AI 理解为“规范 / 要遵守的规则”**
* 但你又明确要求：

  * snippets = Reference only (non-normative)

📌 **必须改名**（二选一）：

```
animation-reference-snippets.md
```

或

```
animation-patterns.md
```

❌ **绝对不要用 `guidelines`**
否则 3 个月后你一定会看到 AI 说：

> “According to animation guidelines…”

这是你现在要避免的。

---

#### 3️⃣ `membership-integration.md`

这个文件**内容是对的，但“层级放错”**。

为什么？

* membership / RBAC / 企业权限
  👉 **是“业务策略 + 工程实现”混合体**
* snippets 的理想状态是：

  * **纯技术模式**
  * 不带业务决策意味

📌 **两种正确处理方式（二选一）**：

**方案 A（推荐）**


**方案 B（更干净）**
把它移动到：

```

```

而不是 snippets。
