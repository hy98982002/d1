# 《行为改变设计的完整决策体系总结》实战读书笔记
## 一、本章真正的作用是什么？
这是整本书的方法论收束章，把“行为科学知识”变成“行为设计决策系统”。

强调：
- 从知识 → 框架（将零散的行为科学理论，整合为可落地的决策框架）
- 从概念 → 流程（把抽象的行为改变概念，转化为 step-by-step 的执行流程）
- 从理解人 → 改变行为（从单纯解读人类行为逻辑，升级为主动设计行为改变路径）

## 二、行为改变的核心认知模型（总原则）
必须用一句话总结：人不是不想行动，而是情境不支持行动。

解释：
- 双系统思维的现实意义：日常行为多由快速、自动的系统1主导，设计需适配这种“省力思维”，而非强行调用消耗认知的系统2。
- 情境比动机更重要：用户的行为选择深受环境线索、社会规范、行动摩擦等情境因素影响，单纯激发动机往往效果短暂。
- 意图—行动鸿沟才是真问题：人们“知道该做什么”与“实际做到什么”之间存在巨大差距，设计的核心是弥合这一鸿沟，而非单纯强化意图。

## 三、CREATE = 行为发生的“六要素系统”
CREATE不是步骤，而是“行为成立的六个前提条件”。

要写清：
- 这是一个“故障排查模型”：当用户未产生目标行为时，可通过CREATE逐一排查哪个环节出现问题。
- 行为失败 = 至少一个环节断裂：提示缺失、直觉反应负面、评估收益不足、能力不匹配、时机不合适、过往经验阻碍，任一环节断裂都会导致行为失败。
- 设计的本质是修复断点：行为改变设计不是从零创造行为，而是针对性修复CREATE中的断裂环节，让六个条件同时满足。

## 四、DECIDE = 行为设计的“工程流程”
DECIDE不是理论，而是“把行为设计工程化”的流程。

强调：

| 阶段 | 本质 |
| ---- | ---- |
| Define | 锁定真实行为（明确目标人群、具体行动与核心结果，避免模糊的“提升健康”） |
| Explore | 找到真实障碍（通过用户研究、行为地图，挖掘CREATE中的真实断点） |
| Craft | 设计情境改变（基于断点，针对性设计干预方案，优化情境而非说服） |
| Implement | 嵌入产品（将干预方案落地为产品功能/流程，而非额外添加） |
| Determine | 因果验证（通过A/B测试、随机对照试验，验证干预与行为改变的因果关系） |
| Evaluate | 迭代收敛（基于数据反馈调整方案，明确“足够好”的标准，避免无限迭代） |

升华：
DECIDE让行为设计从“依赖创意的零散尝试”变成“可复制、可规模化的标准流程”，确保每一步都有明确目标与产出。

## 五、本章真正的深层主题
行为设计不是“说服人”，而是“重构情境”。

并指出：
- 动机不是主入口：用户并非缺乏动机，而是动机难以对抗情境障碍，设计应从“激发动机”转向“降低情境阻力”。
- 说服不是核心手段：强行说服会引发抵触，而重构情境让用户在不消耗意志力的情况下自然选择目标行为，才是可持续的方式。
- 情境工程才是关键：通过优化提示、简化路径、调整时机等情境因素，让目标行为成为“默认选择”或“最省力选择”。

## 六、📦 虚拟案例：健康类App“每周运动2次”习惯养成
### 背景
一款健康App希望用户形成“每周运动2次，每次30分钟”的长期习惯，初期尝试推送“运动有益健康”的提醒后，用户参与率不足10%。

### 1. 用CREATE诊断失败环节
- 提示（Cue）：推送提醒与用户日常流程脱节，易被忽略；
- 反应（Reaction）：“运动”的直觉联想是“累、麻烦”，无积极联想；
- 能力（Ability）：用户不清楚“30分钟运动”具体该做什么，路径模糊；
- 时机（Timing）：未结合用户空闲时段（如下班后、周末），缺乏紧迫性；
- 其他环节（Evaluation/Experience）：短期看不到收益，过往无成功运动经验。

### 2. 用DECIDE设计流程
- Define：锁定目标行为“每周2次、每次30分钟的中等强度运动（如快走、居家瑜伽）”，核心结果“提升运动频率，形成习惯”，目标人群“25-40岁久坐职场人”；
- Explore：通过用户访谈发现，真实障碍是“忘记、不知道做什么、启动麻烦”，而非“不想运动”；
- Craft：设计情境干预——绑定日常流程（下班到家后10分钟为提示）、提供“30分钟无器械模板”（降低能力门槛）、设置“首次完成奖励”（强化积极反应）、好友打卡联动（社会证明）；
- Implement：嵌入产品——首页突出“今日运动模板”、自动推送下班提醒、完成后生成可视化进度条、关联社交账号同步动态；
- Determine：开展A/B测试——实验组用上述干预，对照组仅保留原提醒，验证“运动完成率”“连续参与周数”等指标；
- Evaluate：实验组完成率提升至35%，连续参与3周以上用户占比20%，迭代优化——增加“运动后能量提升”即时反馈，优化模板难度分级。

### 3. 形成长期习惯
- 利用习惯形成机制：固定提示（下班到家）+ 即时反馈（进度、奖励）+ 低摩擦行动（现成模板），让运动从“有意识决策”变成“自动反应”；
- 规避倦怠：定期更新运动模板，设置“阶段性成就勋章”，保持新鲜感的同时强化身份认同（“我是坚持运动的人”）。

## 七、本章的终极升华
行为设计的核心，不是“改变人”，而是“改变人所处的系统”。

人们的行为选择始终被所处的情境系统所塑造，行为设计不是强行扭转人的意愿，而是通过优化提示、能力、时机等系统要素，让目标行为成为更自然、更省力的选择——这既尊重人的天性，又能高效达成行为改变目标。

## 📌 总结
行为改变设计的本质是：**以情境重构为核心，通过CREATE排查行为断点，用DECIDE工程化流程落地干预，让好行为在无额外意志力消耗的情况下自然发生**。
