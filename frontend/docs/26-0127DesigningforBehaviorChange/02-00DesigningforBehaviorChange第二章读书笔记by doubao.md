## CREATE 模型直觉版解释
CREATE不是抽象理论，而是用户从“想做”到“真做”的6个必经关卡，每个关卡都藏着最常见的行动失败点——少一个条件，行动就会卡在半路：
- **C (Cue：触发信号)**：让用户“想起要做”的提醒。失败点：提醒太模糊（“记得学习”）、时机不对（深夜推送），或被其他信息淹没（手机通知太多），用户根本没注意到。
- **R (Reaction：直觉反应)**：用户看到触发信号后的第一感觉。失败点：产品/行动给人的第一印象是“麻烦”“复杂”“不适合我”，比如打开App看到满屏按钮，直觉就想退出。
- **E (Evaluation：评估)**：用户快速权衡“做了有啥好处”“要花多少成本”。失败点：收益太遥远（“3个月后提升效率”），或成本太直观（“要学3个步骤才能用”），觉得“不值当”。
- **A (Ability：能力)**：用户当下是否有条件、有能力完成。失败点：有隐形门槛（需要注册绑定、学操作技巧、找配套资源），或步骤太繁琐，让人“望而却步”。
- **T (Timing：时机)**：当下是否适合行动。失败点：用户正忙、没精力，或觉得“这事不急，以后再做”，最后不了了之。
- **E (Experience：过往经验)**：用户之前的相关经历。失败点：过去用类似产品受挫（“上次学AI工具越学越懵”），或有负面印象，直接抵触新行动。

## 行动失败的真实原因地图
### 为什么“增强动机”通常是最低效的行为改变方式？
1. 动机只覆盖“Evaluation（评估）”一个环节，其他5个环节卡住的话，再强的动机也没用——比如用户想提升文案效率（动机足），但打开AI写作工具要注册、绑定账号、看教程（A环节卡住），再想提升也会放弃；
2. 人天生有“即时偏差”，长期动机（“学会AI能涨薪”）抵不过当下的障碍（“现在要加班，没时间学”），增强动机只是“画饼”，解决不了实际卡点；
3. 动机是消耗品，反复被其他环节卡住后，原本的强动机只会慢慢消退，变成“我确实想做，但这东西太麻烦了”。

### 为什么环境与时机往往比意志力更重要？
1. 环境直接决定C（触发信号）和A（能力）：比如把学习App图标放在手机首页（环境调整），比靠意志力“记得打开”靠谱；简化操作步骤（环境优化），比靠意志力“坚持学”更容易落地——意志力是有限资源，没法长期对抗糟糕的环境设计；
2. 时机（T）决定行动能否“即时发生”：人不会为了“以后可能有用”的事牺牲当下的时间/精力，贴合用户的空闲时段（如通勤、午休）设计行动场景，比让用户“挤时间”（消耗意志力）更有效；
3. 环境和时机是“被动支持”，意志力是“主动消耗”：好的环境能让行动“不费力”，而意志力总会在疲惫、忙碌时失效，长期行为改变靠的是“不依赖意志力的环境设计”。

## 虚拟案例（AI写作工具场景）
### 用户背景
小张，新媒体运营，28岁，经常要写推文、短视频文案，深知AI写作工具能节省时间，下载了一款名为“速写AI”的App，目标是“每周用3次，提升文案产出效率”，下载时动机明确，甚至收藏了“AI文案技巧”文章。

### 逐步对照 CREATE 流程（行动最终失败）
1. **C (Cue：触发信号)**：下载后App只弹出一次“立即体验”，之后再无提醒；小张的习惯是“打开微信/石墨文档写文案”，AI工具的触发信号没和这个现有习惯绑定，每次写文案时都没想起来用（失败点：触发信号孤立、未贴合现有习惯，被忽略）；
2. **R (Reaction：直觉反应)**：3天后偶然看到App图标，打开后首先弹出“请注册账号/绑定手机号/填写行业标签”3个弹窗，接着看到“智能生成、风格定制、关键词优化”等多个功能模块，界面密密麻麻（失败点：第一印象是“复杂、繁琐”，直觉抵触，想“先关了，以后再说”）；
3. **E (Evaluation：评估)**：小张犹豫时，App提示“现在体验可领取7天会员”，但他觉得“要填这么多信息、学这么多功能，就为了领7天会员，不值当”；同时想到“写一条文案也就20分钟，用AI还要调参数，可能更费时间”（失败点：短期收益不直观，感知成本＞感知收益）；
4. **A (Ability：能力)**：勉强注册后，想生成一条短视频文案，却发现需要输入“行业、风格、关键词、字数限制”4个参数，还得学习“优化指令技巧”才能出好内容，试了一次生成的文案不符合预期，还要手动修改半天（失败点：操作门槛高、需要学习成本，当下能力不足以轻松完成）；
5. **T (Timing：时机)**：第一次尝试时是周三晚上8点，小张正在赶明天的推文 deadline，本来就着急，用AI工具没省时间反而添乱，觉得“现在太忙，等周末再好好学”（失败点：当下无闲暇，时机不匹配，无紧迫性）；
6. **E (Experience：过往经验)**：小张之前用过另一款AI工具，也是操作复杂、生成效果差，这次“速写AI”的体验让他想起之前的挫败感，觉得“AI工具都这样，没必要浪费时间”（失败点：过往负面经验放大抵触情绪）。

### 最终失败结论
行动卡在 **C（触发信号缺失）、R（直觉抵触）、A（能力门槛）** 三个核心环节，动机（E环节）从一开始的“强烈”慢慢变成“无所谓”，最终App被卸载。

## 对产品设计的直接启示
1. 优先设计“绑定现有习惯”的触发信号（C）：比如用户打开石墨文档时推送“用速写AI生成文案，10秒出初稿”，比孤立的App弹窗有效，让触发信号主动找到用户；
2. 把“降低能力门槛”放在第一位（A）：初始操作只留1个核心步骤（如“输入文案主题，一键生成”），注册、绑定等非必要步骤后置，让用户“30秒就能看到效果”，避免因复杂操作放弃；
3. 贴合用户的“黄金时机”设计场景（T）：比如针对新媒体运营，在工作日上午10点、下午3点（文案创作高频时段）推送“今日文案模板”，并标注“5分钟完成，直接复用”，降低当下行动的时间感知成本。

### 核心总结
“如果一个人没有采取行动，最不应该先怀疑的是他的动机（或想不想做）。”
