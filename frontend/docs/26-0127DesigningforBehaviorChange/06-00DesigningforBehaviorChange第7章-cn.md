# 第七章 探索背景
## 明确问题→探索背景→设计干预措施→在产品中实施→评估影响→确定后续步骤
三叶草健康（Clover Health）的行为科学团队展示了如何结合定性研究和定量研究来探索用户的生活背景。从调查数据中，该团队发现部分会员反映难以获得所需的医疗服务。于是，团队着手探究背后的原因。

与客户沟通并核对数据后，他们发现低收入社区的居民尤其反映难以获得优质医疗服务。团队提出假设：或许低收入社区吸引的是质量较低的医生，本质上是医疗可及性的问题？

但数据显示事实并非如此：低收入社区拥有优质的医生，且数量足以服务三叶草健康在当地的会员。会员只是没有找到这些医生。可原因何在？

通过采访会员，团队了解到问题不在于可及性，而在于习得性行为。由于这些会员大多一生都面临医疗种族歧视，他们根本不再相信存在好医生——因此也就不会去寻找。这形成了一个自我实现的预言：他们过去遭遇的不公，导致他们在当下继续面临不公。他们会接受遇到的任何一位医生。如果碰巧遇到好医生，就能获得优质服务；但如果遇到糟糕的医生，他们只会将其归咎于不公的制度，并且继续找这位医生看病。

基于对人们生活背景的这种理解，行为科学团队开发了一系列干预措施，包括提供标有当地优质医生信息的注释地图、致电会员并为他们介绍所在社区的更优质医生等。总体而言，超过80%的目标会员被重新引导至优质、公平的医疗服务中。

每个人都有不同的日常习惯、经历和应对世界的方式。要设计出能改变行为的产品，就需要基于这些由习惯、经历和应对方式构成的复杂图景，为用户找到合适的行动方案。该行动方案必须能有效帮助用户实现目标。同时，你还必须在用户需求与开发产品的公司需求之间取得平衡——公司需要创造收入，并以经济高效的方式调配设计和工程资源。

在第六章中，我们明确了公司希望通过产品实现的目标（目标结果，比如减少人们的背部和颈部疼痛），并确定了用户可能采取的、能实现该目标的潜在行动（比如去健身房或节食）。这些步骤帮助我们明确了想要达成的目标。但现实往往不会顺遂我们的计划。

现在，是时候用真实用户来检验我们的假设和目标了。我们将重新审视结果、行动者和行动，并根据公司和用户的需求进行评估。在此过程中，我们还将收集关于目标用户的重要信息，以用于产品设计本身。最终的成果是一份经过完善的问题定义（尤其是我们想要聚焦的行动），以及一份诊断报告，阐明我们认为该行动目前未发生的原因。

具体做法如下：
1.  了解你的用户，以及他们对目标结果和行动的看法。
2.  列出他们可能采取的其他行动方案。
3.  评估这些行动方案并选出最佳方案。
4.  将这个宏观行动拆解为一系列微步骤。
5.  诊断该行动目前未发生的原因。

## 你对用户了解多少？
三叶草健康关于服务不足患者和医疗种族歧视的案例，说明了了解用户的重要性——包括他们的真实生活状况、愿望和兴趣，尤其是他们与你试图改变的行为之间的关联。我们需要收集定性和定量数据，以便更好地针对性设计干预措施，并为用户的生活找到切实可行的解决方案。

### 他们在日常生活中的行为如何？
首先，团队应了解用户的起点。具体来说，他们目前正在做什么？

我以自己过去作为微目标定位师（分析大量个体数据，以识别可能采取行动的人群以及能吸引他们的方式）的经历为例。我曾服务过一家倡导性组织，为了避免他们有起诉我的顾虑，我称之为“行动更多”（ActMore）。该组织是一家环保非政府组织，希望帮助其支持者更深入地参与到志同道合的环保人士社区中。他们有大量已注册电子邮件列表和新闻通讯的人，这些人表示愿意做更多事情，但尚未真正参与进来。首先，“行动更多”需要掌握基本信息——比如年龄、所在地、收入水平、种族、性别、政治兴趣等。我的公司利用该组织已有的数据填补了大部分基本信息。我们可以借此针对性地发出呼吁，并为网站设计提供指导。

这类分析都是常规操作，任何关于产品开发或市场机会评估的书籍（以及“行动更多”这类政治倡导相关书籍）中都有详细介绍。不过，接下来我们开始进入更有趣的部分——聚焦于行为。我们想了解会员对该组织即将举办的一项活动——世界地球日集会——的兴趣程度。我们特别关注会员群体内部的差异：哪些人群会对参与集会的呼吁做出不同反应。每个群体都会收到根据其背景和经验水平量身定制的个性化呼吁。我们正在打造的产品是一项外展活动及相关网站（据我回忆，还有电话沟通环节）。因此，我们开始深入挖掘会员的可用数据，以了解产品需要服务的对象。

在与“行动更多”及其他我合作过的组织的合作中，我发现以下问题对于从行为改变的角度了解用户群体最为相关：
-  对目标行动的过往经验：用户是否有过采取目标行动的经历？（对于“行动更多”来说——他们是否参加过其他类似的集会？）他们如何看待该行动？是否有强烈的情感关联，还是说这对他们而言是全新的领域？增加一项行动比从零开始更容易。与目标相关的现有习惯尤为重要。
-  对类似产品和渠道的过往经验：如果产品采用电子邮件和网站的形式，是否有些用户能定期使用电脑（且知道如何操作），而有些用户则不能？
-  与公司或组织的关系：坦率地说，用户信任你吗？对于不信任你的人和已经了解并喜欢你的人，你需要采用不同的呼吁方式，说服前者会更具挑战性。
-  现有的动机：完全抛开产品提供的东西，用户为什么想要实现这个结果？换句话说，公司可以借助哪些现有因素，而不必独自承担所有工作？动机中一个特别强大的方面是社会动机（积极或消极的）。如果用户采取列表中的各项行动，他们的朋友和家人会怎么看？他们会得到支持、嘲笑，还是仅仅被漠视？
-  行动的物理、心理或经济障碍：这种情况并不常见，但有时确实会出现。是否有部分用户觉得采取该行动特别困难？例如，

行动不便或没有钱去参加集会的用户（事实上，我们在“行动更多”的项目中就遇到了这种情况）。

这五个方面构成了用户的行为画像。为了收集这些信息，你可以使用市场研究和产品开发的标准工具——查找现有的用户人口统计定量数据、开展实地调查、通过焦点小组和一对一实地访谈进行定性研究。如果可能的话，一定要包含对人们的直接观察——看看他们实际的行为表现（而不仅仅是他们说自己会做什么）。如果你只是非正式地探索产品理念，或者由于业务或隐私限制无法与用户直接接触，那么可以与那些接触过目标用户的人交流，从中收集信息。

这种方法显然是建立在现有工具和技术的基础上的。此处的创新之处在于，新增的问题直接聚焦于目标行动，而非用户对产品的感受或他们所谓的“用户需求”，而是关于公司目标结果和目标行动，用户的实际经历、动机和问题。

在观察用户的过程中，你可能会想到关于改变哪些行为的全新想法。例如，对于“闪电”（Flash）这款健身应用，你可能原本设想让用户去健身房，但在观察他们之后，你意识到通过在不同的杂货店购物来健康饮食，可能在控制体重和减轻背部疼痛方面更为有效。将这个想法添加到列表中，与其他想法一起进行评估。你也可能意识到一个（或多个！）早期的想法根本行不通。但如果此时你确定某个早期想法完全不可行，那就省省时间，把它从列表中删除吧。

在此过程中，团队还可能发现一些能引起用户共鸣的特定术语和概念；这虽然不是当前的重点，但仍然很有用——先记下来，为后续的用户体验设计提供参考。

### 利用你已有的知识
无论是否应用行为科学的视角，了解用户在产品开发和设计中都至关重要。事实上，你应该使用的许多技术在这些领域都是通用的：直接观察、用户旅程地图、用户画像等等。

在此，我介绍的这些技术版本，我认为特别适用于应用行为学工作。不过，你可能学到的这些技术有所不同——没关系。利用你已有的知识。正如我们在第五章中讨论的，以用户为中心的问题解决方法并非行为科学所独有；这是一个我们彼此相互学习的共享过程。汲取你认为有用的部分，并将其应用到你已有的基础之上。

### 他们在应用程序中的行为如何？
如果你的公司或组织已经有现成的应用程序或产品，那就太好了。它可以用来了解你拥有的不同用户群体，以及他们将如何对正在考虑的新产品或功能做出反应。如果你还没有服务于这些用户的产品，可以直接跳过这一步。

以我个人的例子来说，我们无法借助“行动更多”之前的产品来了解用户，所以我稍微扩展一下这个例子。假设“行动更多”已经有一个用于促进政治行动的移动和网络平台，名为“立即行动更多”（ActMore Now!）。在研究“立即行动更多”这类现有产品时，首先从用户测试领域的标准问题入手：用户对应用程序的感受如何？他们缺少哪些功能？有哪些不同类型的人使用该产品？谁在系统中最活跃，原因是什么等等。然后再添加一些聚焦于行为的新问题：
-  对目标行动的过往经验：现有应用程序的哪些功能与目标行动类似？用户是否已经形成了可以利用的现有习惯，以支持新的目标行动？
-  对产品的过往经验：哪些功能没有取得成功？这些失败揭示了用户的哪些特征（尤其是注意力有限、缺乏耐心或对某个主题缺乏背景知识）？
-  与公司或组织的关系：他们当前对应用程序的使用是否表明他们信任你？
-  现有的动机：应用程序最成功的功能背后潜藏着哪些动机或兴趣？使用当前应用程序如何与用户的日常生活（尤其是社交生活）相互作用？是否存在围绕使用该应用程序形成的社区？

正如你所看到的，这些问题与分析产品之外的用户时提出的问题非常相似：动机、过往经验和信任。但这些答案作为指导更有价值，因为它们与用户在产品环境中的行为相关。

实际上，这个过程意味着观察、采访和/或调查现有用户，以了解他们对应用程序的看法、挫折和乐趣。一定要包括对人们在日常生活中使用应用程序的直接观察。这也意味着分析应用程序内部现有的使用模式，看看哪些部分的应用程序成功吸引了用户的注意力。尤其重要的是，衡量用户在与应用程序顶级目标相关的任务上的行为，并分析用户群体对现有干预措施的反应。

### 行为画像
接下来，你可以利用收集到的信息，在目标人群中识别出广泛的（潜在）用户群体。我知道这个术语有点负载，但我喜欢生成正式的用户画像——对典型用户的简短描述，以及关于样本用户生活的简单背景陈述。（你也可以用自己的方式来完成，不需要包含生活故事部分，只要能清楚了解人群中的用户群体即可。）由于设计行为改变涉及改变人们生活中的具体细节，因此记住生动、真实、具体的画像非常有价值——而不是模糊地概念化“我们的用户”。

与传统的用户画像不同，这些画像完全围绕行为展开：即那些可能与应用程序产生不同互动、并可能对行为干预措施做出不同反应的用户群体。每个画像都应包含所讨论主题的相关信息；表7-1展示了一种组织方式。这些例子灵感来源于我在HelloWallet和晨星（Morningstar）的工作，其目标行动是帮助那些从未使用过在线储蓄工具的人群为紧急情况存钱。

以下是三种合成行为画像的方法。首先，你可以用这四个问题（类似行动的经验、类似产品的经验等）以开放式的方式激发画像灵感。例如，是否有一组用户在采取该行动方面明显比其他人更有经验？他们是什么样的？这个群体的典型例子是谁？

其次，你可以更正式地使用这四个问题，生成一组固定的选项进行探索。例如，将这四个问题都视为简单的是/否问题。查看每个问题答案的所有可能组合（共有16种）。初步筛选时，你可以排除大多数与你的人群无关的选项（例如，物理障碍可能与你的产品无关；这会立即将选项减少一半）。经过这一轮快速筛选后，你可以思考是否真的有用户符合这些标准，以及他们作为一个群体是什么样的。每个剩下的选项都能为你提供一个画像。

第三，当你拥有关于用户及其行为的历史数据时，可以使用统计或机器学习技术来构建画像，找出哪些用户特征能最好地根据结果对人群进行细分。决策树（随机森林等）或简单的回归分析都可以实现这一目标。我们在晨星就使用这种方法。

我个人更喜欢数据驱动的方法。然而，当没有历史数据时，第二种更正式的方法（尽管看起来可能有些奇怪）却能完全涵盖所有可能的用户类型。它会让你思考每一种“类型”，并判断其是否相关。理想情况下，你的画像应该是详尽且互斥的；也就是说，目标人群中的每个人都最适合且仅适合一个画像。你也可以通过画一个简单的方框来代表整个用户群体（图7-1）。每一条线都划分出人群的另一个部分，直到涵盖所有人。

对于每个画像，在方框中标记出其大致的人群规模比例。如果画像之间有重叠——或者一个画像是另一个的一部分——也没关系。将每个重叠部分视为一个独立的人群群体。当你想不出更多想法时，问问自己：“谁不在这些群体中？他们是什么样的？”为每个群体贴上标签，看看其中是否有一些从行为角度来看是多余的（即你预计他们对产品改变行为的呼吁会做出相同的反应）。然后，利用这些非正式的群体来构建更详细的画像。

在研究用户、了解人群中行为各异的细分群体时，我们也开始了解他们行动的背景。对某人来说，注册你的服务看起来可能很简单直接：只要注册就行了！但对他们来说，我们认为简单的事情并不一定简单。通过深入了解行动路径上的微行为，我们就能发现这一点，以及用户面临的真正障碍。

### 构建行为地图
你知道自己想要做什么（帮助志愿者代表你的事业致电广播节目）。你也了解一些关于用户的情况（他们是感兴趣的志愿者，但大多数人从未作为倡导活动的一部分致电过广播节目）。现在该怎么做？

好吧，要致电广播节目，志愿者需要：
1.  找到一个安静的时间和地点，要有收音机和电话。
2.  确定广播节目。
3.  收听广播节目，寻找合适的致电时机。
4.  获取要拨打的电话号码。
5.  鼓起勇气真正去拨打。
6.  致电节目。
7.  让筛选通话的人相信志愿者有有趣的（且不疯狂的）事情要说。
8.  在广播节目中清晰地表达自己的观点。
9.  告诉志愿者总部通话已经完成，以便其他志愿者可以将精力分散到其他节目中。

这要做的事情可真不少。想象一下，如果你的产品只是告诉用户找到一个广播节目，然后就这个问题给他们打电话。每个人都必须规划一长串需要做的事情，鼓起勇气尝试这个新奇陌生的事情，并且在这个过程中不被其他事情分心。他们还需要做一些认真的事前规划——提前规划好找到节目、抽出有收音机可用的时间去打电话、思考要说什么等等。

祝你好运。事实上，只有一小部分美国人曾经给谈话节目打过电话，而以有预谋的、倡导性的方式打电话的人更是少之又少。

再举一个例子，对于某人来说，开始跑步锻炼不仅仅是走出前门就开始跑那么简单。一些事前步骤包括：（a）准备跑鞋；（b）确定路线和合理的距离；（c）找到时间去跑；（d）记得去跑；（e）确保之前没有吃得太饱等等。同样，要做的事情非常多。

这就是为什么我们需要能帮助人们采取行动的产品，让这些难以处理的任务变得可行。这个过程始于写下用户通常完成行动所需的明显步骤。要详细具体。列出所需的每一项身体和脑力工作，就像广播节目那个例子一样。当我们想要阻止一种行为时，行为地图会概述人们在参与该行为之前采取的所有微步骤。每个这些步骤都为干预提供了机会——帮助人们做出改变。道理是一样的——将重大行动分解为微行为。

现在你有了基本的步骤列表，让我们将其完善为完整的行为地图。

### 写下来或画出来，并添加行为细节
行为地图描绘了用户从当前状态一直到使用产品并完成目标行动（或者对于阻止某种行动来说，是他们在采取要阻止的行动之前所做的事情）的各个步骤。这些步骤中的一些会在产品内部发生，而另一些则需要完全在产品外部进行的行为。该地图会审视用户在每个步骤中的情况，以及他们为什么会继续进入下一步。

对于用户体验（UX）领域的人来说，这听起来应该很熟悉，这也是有意为之。你可以使用多种设计工具来呈现行为地图。我个人偏爱图7-3所示的客户体验地图。它们不仅可以包含个人体验的各个阶段，还可以勾勒出“客户类型”（类似于我们的画像）、挫折和愉悦的方面，以及用户在过程中的情绪。相关工具包括触点清单和地图、同理心地图和用户旅程地图。

图7-3 梅尔·爱德华兹（Mel Edwards）在desonance上发布的客户体验地图的一部分

我没有平面设计背景，所以我使用了简单得多的工具来实现同样的目标：
-  简陋的流程图，侧边附有注释
-  书面叙述，描述用户在每个步骤中的体验和心理状态
-  分层大纲，其中每个顶级要点是用户旅程中的一个步骤，每个要点下方是对用户在该步骤中情况的描述

无论你使用哪种工具来呈现，构建初始行为地图的过程与正常的客户体验地图流程（如果你熟悉的话；如果不熟悉，也不用担心）略有不同。也就是说，确保涵盖以下几点：
1.  写下/画出用户完成行动在现实世界中（而不仅仅是在你的产品中）必须采取的大致步骤序列。（这就是我们在上一节中所做的，列出了人们致电广播节目必须采取的九个步骤。）
    a.  要取得成功，你通常需要规划产品如何间接影响其他这些步骤。
2.  为每个步骤标记如下：
    a.  用户必须在产品内部做的事情
    b.  产品应响应用户所做的事情
    c.  行为地图上所有其他需要“在现实世界中”（产品外部）完成的事情
3.  寻找缺失的步骤，尤其是针对新用户的步骤。
    a.  站在一个从未与你的产品互动过的全新用户的角度思考。一开始是否需要额外的步骤（例如注册）？
4.  寻找一次性步骤。
    a.  站在一个经常与你的产品互动的有经验用户的角度思考。有经验的人是否可以跳过一些步骤？

例如，在奥巴马竞选团队的例子中，志愿者致电广播节目，有些步骤显然必须在产品外部进行，例如“找到一个有收音机和电话的安静时间和地点”以及“收听广播节目，寻找合适的致电时机”。其余大部分步骤都可以在应用程序内完成。重复致电的人可能需要完成步骤2或4（“确定广播节目”和“获取要拨打的电话号码”）。

这就是初始的行为地图。没什么太复杂的。现在让我们来确定应该关注的重点。

### 很少有重大的选择
应用行为科学意味着从不同的角度看待人们的行为。我们不是假设人们会做出明确的选择，然后相应地采取一次决定性的行动，而是关注人们采取的许多小行动，以及这些行动如何共同产生更广泛的影响——无论是有意的还是无意的。而且，即使人们非常有意和深思熟虑，我们也会关注一个单一的重大选择如何在沿途的众多地方被破坏。这就是我们需要行为地图的原因：在看似简单的重大选择中找到隐藏的小步骤。

### 新产品或功能与现有产品或功能
行为地图提供了促成目标行动的一系列微行为。对于现有产品，该地图是描述性的，就像志愿者广播节目系统的地图一样，描述了人们目前需要做的事情。我们利用从现有产品中收集的数据以及人们与产品在现实生活中的互动，仔细追踪微行为。

对于新产品（和功能），行为地图必然更具推测性。它通过详细追踪使用产品或功能真正需要做的事情，帮助我们让那个假设的未来用户互动变得更真实。

在这两种情况下，我们通常会发现现实——人们实际做的（或将会做的）事情比我们想象的要复杂得多。而且沿途有许多地方人们可能会陷入困境。正如你将看到的，行为地图将帮助诊断行为挑战——无论是现有产品中的现有挑战，还是如果我们不仔细思考并现在消除它们，在我们计划构建的产品和功能中即将出现的挑战。

### 阻止行为的行为地图
一个人真正戒烟需要什么？通常，戒烟被表述为一个指令，例如“别抽了！不要点燃香烟（或电子烟）！”但现实要复杂得多。每次吸烟或吸电子烟之前，都有一条社会和身体的路径。有同样吸烟的同事。有随手可得的香烟盒或Juul烟弹。当然，还有内在的依赖性和强烈的习惯。与开始一项行动一样，停止一项行动不仅仅是那个时刻的事情。相反，这是一系列时刻和微行为，最终导致一个重大的选择或行为。

正如这些微行为会给有益的行动带来潜在的摩擦一样，它们也为阻碍负面行动提供了机会。在创建阻止某项行动的行为地图时，要密切关注导致最终行为的微行为，并寻找那些脆弱或容易被干扰的微行为。阻止导致吸烟的某个微行为，可能比在面前有香烟的那一刻阻止吸烟的冲动要容易得多。

例如，如果没有香烟作为提示物，或者工作中的同事没有邀请这个人一起出去，那么“抽还是不抽”这个重大决定甚至不会发生。行为地图帮助我们找到这些创造性的干预机会，而不是在过程中最困难的点（通常是最后一步）采取行动。

## 是否有更适合他们的行动？
你可以将行为地图视为帮助我们理解在哪里进行干预——导致行动的哪个微行为真正需要我们关注。行为地图还可以向我们展示干预到底有多难：改变行为有多难。

有时，最明智的选择不是勇往直前，而是重新思考整个计划。看看是否有更适合作为目标的行动——一种能够实现第六章中概述的目标，但更高效、更有效的行动。让我们来看看如何深思熟虑地重新评估我们关于用户应该采取的行动的核心假设。

### 生成想法的技巧
你如何找出人们可以采取的行动？哪些类型的行动会使目标结果发生？

市面上有很多头脑风暴和创造性思维的技巧。我是通过阅读爱德华·德·波诺（Edward de Bono）的著作入门的，他推广了“横向思维”（lateral thinking）这个术语，但你可以使用任何对你有效的方法。无论如何，至少要想出五个不同的行动，不要停下来。

如果你不知道从哪里开始，以下方法可能会有所帮助：
-  结果发生之前，人们会做什么？
-  公司的独特之处是什么？由于公司的这些独特方面（专业技能、与用户的特殊关系等），哪些用户行动更容易促进？
-  用户已经在做哪些类似的事情？
-  人们为什么没有实现这个结果？
-  人们为什么想要实现这个结果？如果他们有动机，他们最自然会采取什么行动？
-  观察实践中的用户。人们总是能找到创造性的方式来改变自己的行为。观察他们，为产品可以做什么寻找灵感。
-  从一系列随机词汇中汲取灵感（是的，我是认真的——这是爱德华·德·波诺的一种技巧）。这个词与结果有什么关系？人们如何基于这个词采取行动，以支持结果？

如果可能的话，从小处着手。选择人们可以采取的、能实现结果的、简单易行的事情。这样可以更快地进行测试，并且如果需要的话，以后可以进一步扩展。尽可能寻找用户现有的技能和习惯，并在此基础上构建。尝试一些疯狂的想法。在这个阶段，不要自我审查，不要限制那些看似不可能的行动。

行动不一定是用户在使用产品本身时会做的事情——节食就是一个很好的例子。人们通常不会在电脑或手机上登录节食应用程序时吃东西。节食发生在人们选择吃什么和吃多少的时候。许多节食应用程序旨在帮助人们了解信息并做好准备，这样当他们做出饮食选择时，就能避免诱惑，为自己做出更好的选择。不过，这里存在一个风险——产品离行动本身越远，就越不可能促使人们采取行动。

当你想到行动时，行动和结果之间必然会有一个跳跃——假设该行动实际上会起作用，并产生用户和公司寻求的结果。我们稍后会详细阐述这个假设，并判断其风险程度。现在，我建议专注于想出一些很酷的新想法，即使其中一些是不确定的。

### 显而易见的事情是我们的敌人
当你陷入困境时——当你探索了用户的生活背景、绘制了导致行动的微行为地图，并发现这实在太难时，这些生成替代行动的技巧非常有用。然后你就回到原点重新开始。

就我个人而言，我尝试从一开始就使用这些技巧，而不仅仅是在陷入困境时。当我第一次遇到一个行为改变的想法或问题，并被问及如何支持一个目标行动时，我会尝试停下来。我尝试——当然我并不总是成功——质疑我们想要支持的那个行动本身。

对于任何长期存在且困难的问题，通常都会有一个“显而易见”的用户行动。问题在于，对于长期存在且困难的问题，显而易见的事情是我们的敌人。一旦我们开始思考这个问题，一个解决方案往往会立刻浮现在脑海中。它在直觉上感觉是正确的，我们会想要继续推进。这是一种认知错觉。我们的大脑有一个讨厌的习惯，就是将思考的容易程度与真相混为一谈；这就是我们的可得性启发法在起作用。但如果一个问题很困难，那么快速浮现在脑海中的东西很可能已经被尝试过并且失败了。

例如，假设你将目标结果定义为帮助用户存入更多的钱。显而易见的答案是制定预算并在某些方面减少支出。这很明显，但对于大多数用户来说（至少直接来说），这是一个非常难以采取的行动。其他不太明显的行动可能会更有效（例如，自动从你的薪水中扣除钱，这样它就永远不会进入你的支票账户来诱惑你）。同样，在退休方面，当人们不为退休存钱时，显而易见的答案是财务知识普及。如果人们只是了解退休知识，他们就会存钱。不幸的是，事实并非如此。

因此，当你面临一个困难的问题时，我鼓励你寻找那些不显而易见的解决方案。写下显而易见的答案，然后强迫自己想出另外五个不相关的解决方案。使用随机词汇联想。使用横向思维。使用任何能让你超越直觉中感觉正确的解决方案的方法。

话虽如此，我们并不总是需要强大的工具。对于简单的问题，显而易见的事情之所以显而易见，是因为它实际上是正确的做法。你只需要沿着那条显而易见的道路前进并坚持下去。在本书的第一版中，我将这一部分放在了最前面和中心位置——推动每个人在问题定义的初始阶段就思考替代行动。现在它在这里，并且是可选的，以便在不需要这种程度的努力时为你节省时间和精力。

### 选择理想的目标行动
一旦你生成了一系列替代行动，你会怎么做？将它们结合起来，然后缩小范围。

在变得太复杂之前，首先删除那些被已知障碍直接阻止的行动，尤其是如果类似的行动之前尝试过但没有成功的话。接下来，对每个行动按照以下标准进行评分，分为低、中、高三个等级。为了让这个过程更具体，假设目标结果是帮助用户学习一门新语言：
-  对结果的影响：它能有效地实现结果吗？
    换句话说，假设每个用户都毫无保留地采取了这个行动——它会有多大帮助？在学习一门新语言时，重复一个单词的行动不是很有效，得分为“低”；练习一些句子可能得“中”；沉浸在外国环境中得“高”。
-  用户的动机：用户有多大的动机去采取这个行动？
    利用你收集的关于用户现有动机以及他们围绕产品的社交互动的数据。用户可能真的很兴奋去外国旅行，或者通过亲自练习语言技能结交新朋友（这两个选项得“高”分）。他们可能对死记硬背没有什么兴趣（得“低”分）。
-  用户的难易程度：这个行动与用户在日常生活中已经做的事情（包括他们与现有产品的互动）有多相似？
    沉浸在外国环境中学习语言（通常）得“低”分。重复单词或练习句子可能得中或高分，这取决于你对用户的了解。现有习惯总是得“高”分。需要用户停止现有习惯的行动总是得“低”分（见第三章）。这个过程可能需要主题专家来评估该行动对用户可能产生的影响。
-  公司的成本：公司围绕该行动实施解决方案有多容易？
    真正的语言沉浸对于在线产品来说得“低”分。与母语人士进行实时对话可能得“中”分，这取决于公司现有的资源和能力。为用户提供可以重复的脚本会很容易。这个评分可能需要首席工程师来评估潜在的资源成本。

有了这些评分，寻找明显的异常值。如果有一个明显的赢家，那就太好了。如果没有，删除任何明显的失败者。如果这还没有足够缩小范围，根据公司的业务战略，判断什么是最重要和可行的。如果资源紧张，那么实施成本自然就变得相当重要了！

行为经济学在这里可能会有所帮助——（大多数）用户在某些行为和思维方式上本来就更困难，我们在第一章中涵盖了一些高级课程。例如，需要大量心理计算的行为是困难的，并且通常会被避免。专注于长期收益而非短期损失的行动也与我们的许多认知机制相悖（损失带来的痛苦比收益带来的快乐更大，短期收益比长期收益更受重视）。

除此之外，不幸的是，没有更多的指导了。继续缩小范围，直到只剩下一个首选方案，或者有两个势均力敌的选项可以在实践中进行测试。

有了新的行动，更新问题定义。写下新的行动，并填写这些细节：是否需要开始或停止，谁来做，以及导致行动的微行为。

### 更新行为画像
如果团队决定改变目标行动，我们必须重新审视行为画像，看看是否需要更新。换句话说，快速浏览每个五个问题（类似行动的经验、类似产品的经验等），并根据我们新的用户行动生成必要的额外画像。通常，生成的画像在各种行动中可能是相同的，但要准备好它们可能会有所不同。请记住，与正常的用户体验画像不同，行为画像与特定的目标行动相关并由其定义：因为目标是创建一组可能对产品改变行为的尝试做出不同反应的画像。

## 用CREATE框架诊断问题
现在我们知道了个人要取得成功需要采取哪些微行为，我们可以更具体地看看我们想要如何改变环境。为此，我们回到第二章和第三章中的CREATE行动漏斗，既帮助人们采取积极行动，也阻碍消极行动。

### 行为总是与背景相关的
行动总是发生在特定的时刻。虽然准备工作可以随着时间的推移进行，但任何特定的行动都只发生在那个时刻。虽然这可能看起来很明显，但理解其影响是一个令人惊讶的困难教训。这意味着即使有人经常想到这个行动（或产品），如果他们在那个重要的特定时刻没有想到它，也没有用。同样，如果人们总体上有行动的动机，但由于某种原因在那个重要的特定时刻没有动机——就不会有行动。

### 诊断人们为什么不开始行动
多年来，我与许多个人和公司合作，写下他们的行为地图。通常，当参与者绘制出他们想要支持的行为后，他们会说两件事：
-  哇，有很多步骤！我们要求用户做的事情比我们想象的要复杂得多！
-  我知道该怎么做了！

仅仅通过以更结构化、更有针对性的方式探索问题，解决方案可能就会变得清晰直接。当情况并非如此时，我们可以使用CREATE漏斗来帮助我们诊断核心的行为挑战（然后努力解决它）。

为了看看这是如何运作的，让我们继续前面关于帮助政治志愿者致电广播节目的例子。我们列出了九个不同的步骤，从找到一个安静的时间打电话到之后告诉志愿者协调员。有了这个行为地图和我们收集的关于用户及其情况的数据，我们会问：“问题在哪里？”

对于现有产品，人们在哪里放弃？他们在哪个阶段停止？当然，有些人会在不同的阶段遇到困难，但我们正在寻找最大群体陷入困境的地方。

对于新产品，分析更具推测性，但类似。根据你对用户的了解，他们在这一系列微行为中可能会在哪里遇到困难？

对于现有产品和功能，这种分析是基于你收集的关于用户的实证数据。图7-4是我为人力资源专业人士撰写的《改善员工福利》（Improving Employee Benefits）一书中的一个例子，该书探讨了退休计划、健康和福利计划等背景下的行为改变。

| 总邮件接收人群 | 100% |
| ---- | ---- |
| 未收到邮件 | 8% |
| 打开邮件 | 29% |
| 点击链接 | 7% |
| 离开第一页 | 6% |
| 选择一个计划 | 5% |
| 选择一个提供者 | 4% |

图7-4 一种直观的方式来可视化员工在哪个环节放弃，使用转化漏斗

一旦我们确定了一个有问题的步骤，我们就使用CREATE框架。在那个特定的步骤中，在那个潜在行动的特定时刻，是否有采取行动的提示？（并且它是否足够？）这个人对那个行动有什么情绪或直觉反应？这个行动是否有动机，收益是否大于成本？等等。每当答案是否定时，那就是一个行为障碍。这就是我们在设计过程中要关注的地方。

在广播节目这个例子中，一个明显的有问题的步骤是“实际打电话”——也就是说，克服采取这个新的、不寻常行动的恐惧和不确定性（一种情绪反应）。

因此，诊断是一个三部分的过程：
1.  首先，我们确定阻止人们的微行为（或者对于新产品，可能阻止人们的微行为）。这就是我们的行为地图。
2.  其次，我们检查哪个微行为似乎是个问题。人们在哪里放弃（或者可能放弃）？
3.  第三，我们使用CREATE行动漏斗来确定可能的行为原因。

有了这三个（一张地图、地图中存在问题的一个或多个点，以及该问题的原因），我们就有了诊断结果。我们有了开始设计解决方案所需的东西。

这是针对开始一项行动。让我们看看类似但略有不同的情况：阻止一项行动。

### 诊断人们为什么不停止行动
关于阻止一项行动的好消息是，诊断问题更容易——即使解决它并不容易。一个人要采取（负面）行动，CREATE的每个因素都必须到位。诊断需要概述这些因素目前是什么。触发人们采取行动的提示是什么？他们有什么直觉或情绪反应？等等。

当你帮助用户停止一项行动时，至关重要的是要知道该行动是否是习惯性的；也就是说，这是否是人们有意识思考的事情。这是因为，正如我们在第二章中谈到的，习惯的运作方式与有意识的行为不同。在习惯中，评估、时机和经验步骤在很大程度上被跳过了（或者它们是内在固化的）。一个提示会触发一个反应，前提是这个人有采取行动的能力。我们关注的是CREATE中的C-R-A部分，而不是整个步骤。

以下是诊断一个你想要阻止的常见习惯的例子：疯狂观看在线电视。导致疯狂观看的微行动是什么？
1.  拿起电脑或手机。
2.  登录Netflix应用程序或网站。
3.  选择一部电影或电视剧。
4.  观看它。
5.  让自动播放加载下一集。
6.  继续观看，等等。

在每个步骤中，要么有习惯性的元素（C-R-A），要么有有意识的选择（CREATE）。拿起手机通常是习惯性的。提示是什么？是看到手机（外部提示）或感到无聊（内部提示）。

诊断一个你想要阻止的行为需要：
1.  确定导致行动的微行为——行为地图。
2.  在每个微行为中，确定它是习惯性的还是有意识的（通常如果最终行动是习惯性的，那么导致它的行动也是习惯性的，但不一定）。
3.  对于有意识的行动使用CREATE，对于习惯性的行动使用C-R-A，来绘制每个微行为当前的促成因素。

行为地图、我们对行为性质的理解以及促成CR(E)A(TE)因素的列表，正是我们设计解决方案所需要的。

给你一个预览：我们都听过这样的建议，通过把手机放在看不见或听不见的地方来避免分心。这是在第一个微行动中进行干预的一个例子（具体来说，是在CREATE行动漏斗的提示阶段进行干预）。假设这是不可能的，你无法阻止人们拿到电脑或手机。但你可以改变人们登录的方式（将密码改成不容易记住的！）或自动播放过程（更改设置，使自动播放不会发生）。

自动播放的行为问题在于它是一种“作弊”：它将工作负担从个人转移到了软件上。我们可以通过取消这种巧妙的设计，将工作负担重新交还给个人来应对。换句话说，关闭自动播放。当阻碍一项行动时，我们会使用这个行为地图和促成因素列表，寻找一个对后续过程既至关重要又易于改变的微行为。然后我们使用CR(E)A(TE)来确定在哪里设置行为障碍。

## 付诸实践
本章的全部内容都是关于检验你对用户及其情况的假设，以便完善我们对他们将做什么的愿景，并诊断他们面临的具体行为障碍。

以下是你需要做的：
1.  研究并记录用户的特征，尤其是关于行动的过往经验、产品的过往经验、现有的行动动机、他们与公司的关系（信任）以及行动的障碍。
2.  生成行为画像——你期望会对产品改变行为的尝试做出不同反应的用户群体。
3.  制定行为地图，展示行动者从当前状态到采取行动所采取的步骤序列。
4.  根据行动对用户的有效性、成本、动机和可行性，对用户可能采取的替代行动进行评分。
5.  根据这些标准选择理想的目标行动。

你会知道出现问题的迹象：
-  看起来所有用户都是一样的——他们通常不是。你可能没有深入挖掘他们现有的经验和行为。
- 在对潜在行动进行评分时，所有行动的评分都相似，或者所有行动对公司来说成本太高，或者对用户来说不可行，不切实际（抱歉，回去再想更多用户行动）。

交付成果：
-  关于用户的详细观察。
-  一组用户画像，表明应用程序的主要用户群体（或潜在用户群体）及其特征。
-  概述个人所采取的微行动的行为地图。
-  在该行为地图上，你认为你的用户面临或将会面临的特定障碍——一份诊断报告。
-  一份可能更新的项目摘要，包括目标结果、行动者和行动。

### 工作表：行为地图
描述用户从无行动到采取行动需要采取的每个微行为。然后询问在每个步骤中，行动的六个CREATE前提条件是否都满足。勾选已有的前提条件，并简要描述它们，以供参考。如果缺少某个前提条件，思考如何重新构建行动、改变环境或教育用户，以帮助他们完成这个过程。

| 用户的初始状态是什么？ | 久坐不动，通常不锻炼 |
| ---- | ---- |
| 用户首先做什么？ | 打开邀请下载应用程序的电子邮件 |
| 提示（Cue） | ☑ 来自雇主的电子邮件 |
| 反应（Reaction） | ☑ 中立，会收到雇主的各种电子邮件 |
| 评估（Evaluation） | ☑ 打开成本低，总体来说很重要 |
| 能力（Ability） | ☑ 容易 |
| 时机（Timing） | ☑ 来自公司的电子邮件应该尽快打开 |
| 经验（Experience） | ☑ 中立 |
| 用户接下来做什么？ | 使用员工ID和唯一密码安装应用程序 |
| 提示（Cue） | ☑ 电子邮件中的行动号召 |
| 反应（Reaction） | ☐ 唉，又一个应用程序 |

在我们的健身应用程序这个例子中，我们很早就发现了两个问题：用户对下载和使用另一个应用程序的负面情绪反应，以及无法登录创建账户。

### 工作表：完善行动者和行动
对于某些产品，尤其是现有产品，行动者和行动是显而易见且没有疑问的。在这种情况下，跳过这个练习。然而，当你探索背景时，你可能会更多地了解你的用户及其情况，并意识到你最初的假设是不正确的。如果你认为该产品可能会吸引或帮助另一个群体，或者你的团队正在提供那些过去没有奏效的相同陈旧解决方案，这个工作表可以帮助你重新审视和完善它们。

| 行动：集思广益，人们可以通过你的产品或沟通采取四种截然不同的行动来实现你的目标结果。在思考可能的行动时，请记住以下几点： |
| ---- |
| 人们目前实现结果面临的障碍 |
| 结果发生之前需要发生什么 |
| 你的公司如何独特地帮助人们实现结果 |
| 目前已经实现该行动的人们正在做什么 |
| 行动1：每周独自跑步两次，每次开始跑两英里。 |

为了便于讨论，让我们假设对于我们的“闪电”（Flash）健身应用程序，公司已经确定了行动（去健身房）和目标用户（久坐的白领员工），并且我们将在整个后续过程中继续围绕这些目标展开。在工作手册中，你会找到另一个练习，你可以用它来集思广益不同类型的行动者，并在可能的行动者和行动之间进行评估。
