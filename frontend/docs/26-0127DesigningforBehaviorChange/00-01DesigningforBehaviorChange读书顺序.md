# 🧠 必读核心章节（真正影响Doviai成败）

## 🥇 第一优先级（必须精读）

### **📘 第 2 章 — Creating Action**

这是整本书的发动机。

里面提出了：

> **CREATE 行为漏斗模型**

| 要素         | 对应产品问题           |
| ---------- | ---------------- |
| Cue        | 用户为什么会开始学习？      |
| Reaction   | 用户看到页面第一反应是什么？   |
| Evaluation | 用户会不会怀疑自己学不会？    |
| Ability    | 学习门槛是否太高？        |
| Timing     | 用户什么时候最容易开始？     |
| Experience | 用户过往学习失败经验会不会阻碍？ |

👉 你所有页面结构都要围绕这个模型。


---

### **📘 第 6 章 — Defining the Problem**

这是产品经理的行为设计版本。

讲的是：

> ❌ 不要设计“课程展示网站”
> ✅ 要定义“用户要发生的最小行为”

它教你定义：

* Target Outcome（目标结果）
* Target Action（最小行为）

👉 你现在Doviai最需要这个，否则会变内容网站。


---

### **📘 第 7 章 — Exploring the Context**

这是把“行为”变成“页面结构”的桥梁。

提出：

> **Behavioral Map（行为路径图）**

就是你Doviai要做的：

用户从
不知道学什么 → 选方向 → 开始 → 继续 → 成功

每一步行为拆解。

这章直接决定你的页面层级设计。


---

### **📘 第 9 + 10 章 — Crafting the Intervention**

这两章是：

> **“怎么让用户真的做出行动”实战技巧库**

教你：

* 怎么设计提示（Cue）
* 怎么降低心理阻力（Evaluation）
* 怎么减少认知负担（Ability）
* 怎么利用时机（Timing）

这些直接变成你：

* 首页结构
* CTA设计
* 推荐机制
