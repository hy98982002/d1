### ⚠️ 建议 1：`level-name-translation.js` 的等级确认

你现在保留了这个规则，但 **md 中没有明确它是 ERROR 还是 WARN**。

建议明确写一句（非常重要）：

* 如果是 **语言展示差异（如 UI 文案）** → WARN
* 如果是 **slug / @id / JSON-LD 中翻译** → ERROR

否则未来别人维护时会犹豫。

---

### ⚠️ 建议 2：`scan.js` 文件类型白名单

你现在描述的是：

```text
.vue / .ts / .js / .json / .md
```

建议你在 md 中**明确一条排除规则**：

* ❌ 不扫描 `node_modules`
* ❌ 不扫描 `dist` / `build`
* ❌ 不扫描 `.git`

这是**CI 性能与误杀控制问题**，不是洁癖。

---

### ⚠️ 建议 3：ERROR / WARN 输出顺序

工程经验建议：

* **ERROR 先输出**
* WARN 后输出
* 最后 summary

这能让 CI 日志**第一眼就看到“该不该停”**

你已经有 `utils/report.js`，这是顺手一改的事。
