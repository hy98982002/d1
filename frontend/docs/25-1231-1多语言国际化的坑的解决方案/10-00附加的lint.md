# aeo-lint 规则：`no-entity-id-in-hreflang`

## 规则级别

* **ID**：`AEOLINT-HREFLANG-ENTITY-ID`
* **Severity**：`error`（CI 必须失败）
* **Category**：`semantic-integrity`
* **Auto-fix**：❌ 不可自动修复（必须人工判断）

---

## 规则定义（规范文本，可写进规则文档）

```md
Rule: no-entity-id-in-hreflang

Entity @id MUST NOT be used in hreflang.

hreflang MUST reference page URLs only.

Entity identity and page localization are separate layers.

Any usage of /_entity/ URLs inside <link rel="alternate" hreflang="...">
is a semantic integrity error.
```

---

## 检测目标（Lint Scope）

### 扫描对象（必须全部覆盖）

* `<link rel="alternate" hreflang="...">`
* `<xhtml:link rel="alternate" hreflang="...">`（sitemap / SSR）
* 未来可扩展：

  * `<meta property="og:locale:alternate">`（可选）

---

## 判定条件（Fail 条件）

### ❌ 直接失败（任何一条命中即 error）

1. **hreflang href 包含 entity 路径**

   ```txt
   /_entity/
   ```

2. **hreflang href 与 JSON-LD 中任一 @id 完全相同**

3. **hreflang href 指向非内容页结构**

   * `/entity`
   * `/_entity`
   * `/schema`
   * `/id`

---

## 合法示例（lint 必须通过）

```html
<link rel="alternate" hreflang="zh-CN" href="https://www.doviai.com/levels/intermediate">
<link rel="alternate" hreflang="en" href="https://www.doviai.com/en/levels/intermediate">
<link rel="alternate" hreflang="zh-Hant" href="https://www.doviai.com/zh-hant/levels/intermediate">
```

---

## 非法示例（lint 必须失败）

```html
<link rel="alternate" hreflang="en"
      href="https://www.doviai.com/_entity/level/Intermediate">
```

```html
<link rel="alternate" hreflang="zh-CN"
      href="https://www.doviai.com/_entity/course/ui-design">
```

## 规则实现（JS / Node 伪代码，可直接落地）

```js
export function ruleNoEntityIdInHreflang(document, jsonLdEntities) {
  const violations = []

  const hreflangLinks = document.querySelectorAll(
    'link[rel="alternate"][hreflang]'
  )

  hreflangLinks.forEach(link => {
    const href = link.getAttribute('href')
    if (!href) return

    // Rule 1: entity path
    if (href.includes('/_entity/')) {
      violations.push({
        ruleId: 'AEOLINT-HREFLANG-ENTITY-ID',
        message: 'Entity @id MUST NOT be used in hreflang',
        node: link,
        href
      })
      return
    }

    // Rule 2: exact match with JSON-LD @id
    if (jsonLdEntities?.some(e => e['@id'] === href)) {
      violations.push({
        ruleId: 'AEOLINT-HREFLANG-ENTITY-ID',
        message: 'hreflang href matches JSON-LD @id',
        node: link,
        href
      })
    }
  })

  return violations
}
```
