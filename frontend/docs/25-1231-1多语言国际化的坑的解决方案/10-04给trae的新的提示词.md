## ✅ Rule A：no-entity-id-in-page-metadata

### 规则名（文件名建议）

```txt
no-entity-id-in-page-metadata.js
```

### 规则目的（给 README / 代码注释）

> Prevent entity canonical @id from leaking into page-level metadata.

### 检测目标

扫描以下 **页面级字段**：

* `<link rel="canonical">`
* `<link rel="alternate" hreflang="*>`
* `<meta property="og:url">`
* `<meta name="twitter:url">`
* 任何 `<link>` / `<meta>` 中的 URL 值

### 违规条件（ANY 命中即 ERROR）

```text
IF a URL contains "/_entity/"
AND the context is page metadata (link / meta)
THEN ERROR
```

### 错误等级

```txt
ERROR
```

### 错误信息（标准化，便于 CI）

```txt
Entity @id MUST NOT appear in page-level metadata
(canonical / hreflang / og:url / twitter:url).
Entity identity and page URLs are separate layers.
```

### 示例（写进 README / fixtures）

❌ 错误：

```html
<link rel="canonical" href="https://www.doviai.com/_entity/level/Intermediate">
```

✅ 正确：

```html
<link rel="canonical" href="https://www.doviai.com/levels/intermediate">
```

## ✅ Rule B：entity-namespace-not-indexable

### 规则名（文件名建议）

```txt
entity-namespace-not-indexable.js
```

### 规则目的

> Ensure /_entity/ is treated as a semantic identity namespace, not a content page.

### 检测目标（任选其一命中即可）

#### 1️⃣ HTML 页面中出现 `/_entity/` 且：

* 包含 `<title>`
* 包含 `<meta name="description">`
* 包含 `<h1>`
* 或被扫描为“页面型 HTML 文件”

#### 2️⃣ JSON-LD / HTML 中出现以下组合：

```text
URL starts with "/_entity/"
AND is referenced as:
- canonical
- og:url
- sitemap entry
```

### 违规等级（建议）

```txt
ERROR
```

（如果你想更保守，第一版可以 WARN，下一版升 ERROR）

### 错误信息

```txt
/_entity/ is a semantic identity namespace.
It MUST NOT be treated as a navigable or indexable page.
```

### 设计原则说明（写在规则注释里）

```txt
Entity pages may be fetched by machines,
but MUST NOT behave like content or SEO landing pages.
```

```text
Please add two new CI-level rules to aeo-lint.

Rule A: no-entity-id-in-page-metadata
- Entity canonical @id (/_entity/*) MUST NOT appear in any page-level metadata.
- This includes:
  - link[rel=canonical]
  - link[rel=alternate][hreflang]
  - meta[property=og:url]
  - meta[name=twitter:url]
- If any URL in these contexts contains "/_entity/", raise ERROR.
- Error message must clearly state that entity identity and page URLs are separate layers.

Rule B: entity-namespace-not-indexable
- The "/_entity/" namespace is semantic identity only.
- It MUST NOT be treated as an indexable or navigable content page.
- Raise ERROR if:
  - an HTML page under "/_entity/" contains title/description/h1, OR
  - "/_entity/" URLs are used as canonical / og:url / sitemap entries.
- Include a short rationale comment in the rule:
  "/_entity/ is for semantic identity, not content pages."

Please:
- Implement both rules under tools/aeo-lint/rules/
- Register them in index.js
- Add concise documentation rows to aeo-lint README
- Do NOT modify /CLAUDE.md (root constitution)
```
