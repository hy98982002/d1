## 三、⚠️ 必须指出的一个「隐藏风险」（很重要）

### 问题不是“规则错”，而是**执行范围略粗**

这一段：

```js
if (file.path.includes('/_entity/') && /\.(html|vue|md)$/.test(file.path))
```

**隐含假设是：**

> 所有出现 `/_entity/` 的文件，都是“页面级文件”

但你的体系里，**将来极有可能出现**：

* `/ _entity /level/Intermediate.json`
* `/ _entity /program/logo-design.jsonld`
* 甚至 `/ _entity /xxx.ts`（构建生成）

### 潜在后果：

* 如果未来你生成：

  * **纯 JSON-LD / RDF / JSON 文件**
* 但路径仍在 `/_entity/`
* 里面合理地包含 `name` / `description`

👉 **这条规则会误杀**

* `.jsonld`
