## 四、执行与集成

### 1. 本地运行
```bash
node tools/aeo-lint/index.js src
```
- ✅ 全通过 → exit 0
- ❌ 命中 ERROR → exit 1
- ⚠️ 仅有 WARN → exit 0

### 2. CI 集成
```yaml
- name: AEO Structure Lint
  run: node tools/aeo-lint/index.js src
```
