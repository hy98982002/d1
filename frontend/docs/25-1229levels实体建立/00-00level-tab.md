## 把问题拆成 3 层（这是关键）

你现在其实在同时处理 **三种不同语义的东西**，而大多数人会把它们混在一起。

### ① 你现在的这 3 个按钮，本质是什么？

从你截图和描述来看，它们是：

> **首页内的内容分区 Tab（Content Switcher）**

特征非常明显：

* 页面 **不跳转**
* Hero、标题不变
* 只是课程列表变
* URL 用来 **保持状态 / 可分享**

👉 **这不是“页面导航”，而是“视图状态切换”**

✅ **这个定位是完全正确的**

---

### ② 那 `/?stage=advanced` 在语义上是什么？

非常重要的一句话：

> **`?stage=advanced` = UI State，不是 Knowledge Entity**

也就是说：

* ✔ 可以用来：

  * Tab 状态保持
  * 刷新不丢状态
  * 分享给别人“你看到的是高阶”

* ❌ 不能用来：

  * 定义“什么是高阶”
  * 被 JSON-LD 的 `educationalLevel` 引用
  * 被搜索引擎当作一个“学习阶段页面”

**你现在把它当 Tab，用得完全正确。**

---

### ③ 那 `/levels/*` 是干嘛的？（这是很多人真正搞错的）

`/levels/*` **不是给 Tab 用的**，而是给 **搜索引擎 + 知识图谱 + 语义引用** 用的。

它的职责是：

* 定义：

  * 什么是 Beginner / Intermediate / Advanced
* 解释：

  * 学习难度
  * 适合人群
  * 预期能力
* 聚合：

  * 属于该 Level 的课程
* 成为：

  * `DefinedTerm`
  * `educationalLevel.@id`
  * 稳定的 canonical 实体

👉 **这是“知识页面”，不是“交互页面”**
