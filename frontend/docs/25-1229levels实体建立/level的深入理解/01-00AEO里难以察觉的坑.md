# 坑 1：Level 页面“出生了，但没有主权”（最致命）

### 表现形式（非常常见）

你将来会做：

```
/levels/beginner
/levels/intermediate
/levels/advanced
```

但页面内容是：

* 课程列表
* 一点说明
* 和首页 Tab 展示高度相似

**问题在于：**

> 搜索引擎会认为：
> **这是“另一个课程聚合页”，不是 Level 的定义页**

### 为什么这是结构性错误？

AEO 不是看“有没有这个页面”，
而是看：

> **这个 URL 是否是“解释该概念的最高权威来源”**

如果 Level 页：

* 没有回答：

  * “什么是 Intermediate？”
  * “进入前需要什么能力？”
  * “学完后你能做什么？”
* 只是课程堆

那在知识图谱里：

```
Intermediate → 没有清晰定义 → 失去实体主权
```

### 后果（真实后果）

* `educationalLevel.@id` 形式上正确
* **语义上不被信任**
* Level 页面不会成为“被引用节点”
* 你的体系在 AEO 中**退化成标签系统**

### 你该提前做的（不是以后）

> **Level 页面第一职责：解释概念，不是列课程**

课程只是**证明这个 Level 存在的证据**，不是主体。

# 坑 2：Program 与 Level 的“角色重叠”（迟早打架）

### 你未来一定会遇到的场景

你会想做这种页面：

* “高阶 · AI 设计实战路径”
* “Intermediate 设计师成长路线”

然后你会犹豫：

> 这是 Program？
> 还是 Level 页面？

### 这里有一个**绝对规则**

> **Level = 横切面（难度）**
> **Program = 纵向路径（顺序）**

但 80% 的项目会在这里翻车，因为：

* Program 页面开始解释“什么是高阶”
* Level 页面开始暗示“学习顺序”

### 一旦混了，会发生什么？

* Schema 关系开始模糊
* `isPartOf / hasPart` 变得不可信
* 搜索引擎无法判断：

  * 谁是“路径定义者”
  * 谁是“能力层级定义者”

### 后果

> **你的 Program 失去“路径权威”，
> Level 失去“难度权威”**

两个一起降级。

# 坑 3：Course 页面“偷偷解释 Level”（隐蔽但严重）

这是一个**你非常容易踩**、而且**大多数人意识不到**的坑。

### 典型表现

在 Course 页面写：

> “本课程适合有一定基础、想进阶的设计师”

听起来没问题，对吧？

但如果你写多了，会变成：

* Course A 说 Intermediate 是 A
* Course B 说 Intermediate 是 B
* Course C 说 Intermediate 是 C

### 在 AEO 里，这是灾难

因为：

> **一个概念只能有一个权威解释源**

Course 页面**没有资格解释 Level 的含义**，
它只能：

* 引用 Level
* 适配 Level

### 后果

* Level 定义被“稀释”
* 搜索引擎无法确定：

  * “Intermediate 到底意味着什么”
* Level 实体信号变弱

# 坑 4：多语言 / 国际化时，Level 的 @id 崩溃

这个坑你**现在没做国际化，但将来一定会做**。

### 你将来可能会这样做（错误示例）

```txt
/levels/intermediate        （中文站）
/en/levels/intermediate     （英文站）
```

然后 JSON-LD 里：

```json
"educationalLevel": {
  "@id": "https://www.doviai.com/levels/intermediate"
}
```

### 问题来了

* 英文页面引用中文 Level
* 或你复制一份：

  ```txt
  /en/levels/intermediate
  ```

  但 **@id 变了**

### 这在 AEO 里意味着什么？

> **同一个概念，被你声明成了两个实体**

搜索引擎会直接：

* 合并失败
* 或选择其中一个
* 或降低可信度

### 这是一个**结构级返工点**

你必须提前决定：

> **Level 的 @id 是否是跨语言稳定的“抽象实体”**

否则国际化 = 语义自残。

# 坑 5：Level 没有“被引用统计价值”（慢性伤害）

这个坑不是马上爆炸，但会**慢慢拖死你**。

### 表现

* Course 正确引用 Level
* Level 页面存在
* 一切“看起来都对”

但：

* Level 页面没有内部链接权重
* 没有被 Program 引用
* 没有被 FAQ / Guide 引用

### AEO 的冷酷现实

> **实体是否重要，不取决于你有没有定义它，
> 而取决于：
> 有多少“其他实体指向它”。**

如果 Level：

* 只被 Course 引用
* 没有成为“中心节点”

那它只是一个**被动枚举值**。

### 结果

* Level 永远成不了“知识枢纽”
* 你体系再完整，也无法放大权重
