# 🧠 这本书真正的核心结构（你要抓的主线）

整本书底层只讲一件事：

> **如何让一个产品持续推动用户改变行为**

作者用的是 **自我决定理论 SDT** 三大心理需求做骨架：

| 心理需求                | 产品层对应问题          |
| ------------------- | ---------------- |
| **Autonomy 自主感**    | 用户是否觉得“这是我自己的选择” |
| **Competence 胜任感**  | 用户是否觉得“我在变强、有进步” |
| **Relatedness 连接感** | 用户是否觉得“我不是一个人”   |

这三条 = 行为长期持续的唯一引擎。

# 📘 1️⃣ **Designing for Behavior Change — Stephen Wendel**

### 🧠 核心定位

这是一本**行为改变的工程学教科书**。
不是“如何做界面”，而是：

> **“如何科学地设计一个能改变人行为的系统”**

它在干的事情是——
🔬 把行为经济学 + 心理学 → 变成一个**可复用的产品开发流程**

### 📦 它提供的是：

| 模块                                                           | 对 doviai 的意义                      |
| ------------------------------------------------------------ | --------------------------------- |
| CREATE 模型（Cue→Reaction→Evaluation→Ability→Timing→Experience） | 这是你课程训练路径的**行为漏斗结构骨架**            |
| DECIDE 流程（Define→Explore→Craft→Implement→Determine→Evaluate） | 直接就是你平台功能开发的“行为版本敏捷开发流程”          |
| A/B 实验与因果评估                                                  | 这是你将来课程、训练库、行为训练系统能否有效的**科学验证方法** |
| 行为指标设计                                                       | doviai 要做“学习行为追踪”，这本书就是指标来源       |
| 团队建设                                                         | 未来你做行为训练AI团队的组织结构参考               |

### 🎯 适合什么场景？

* 平台级产品
* 长周期行为改变（学习、训练、习惯养成）
* 需要验证“是否真的有效”
* 做“行为系统”的人

👉 **这本是“行为系统架构书”**

# 📙 2️⃣ **Engaged: Designing for Behavior Change — Amy Bucher**

### 🧠 核心定位

这是一本**UX 设计师视角的行为改变设计书**。

不是系统，而是：

> **“如何把心理学直接变成界面和产品体验设计”**

她的核心理论不是行为经济学，而是：

🧩 **Self-Determination Theory（自我决定理论）**

> 人长期愿意做一件事，必须满足：

* Autonomy（自主感）
* Competence（胜任感）
* Relatedness（连接感）

### 📦 她提供的是：

| 模块           | 对 doviai 的意义     |
| ------------ | ---------------- |
| 如何给用户“选择感”   | 课程路径设计、任务分支、学习路线 |
| 如何降低决策负担     | UI 设计、课程呈现方式     |
| 如何设计“成长反馈”   | 你的训练库“阶段反馈机制”    |
| 如何通过“社交”增强坚持 | 学员社群、学习榜单        |
| 如何设计“未来自我”   | 长期学习动机维持         |

👉 **这本是“行为UX设计手册”**
