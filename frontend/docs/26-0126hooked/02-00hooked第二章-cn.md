# 第二章 触发（Trigger）
尹（化名）二十五六岁，住在加利福尼亚州帕洛阿尔托，就读于斯坦福大学。像这所名校的学生一样，她举止沉着、谈吐得体，但一整天下来，却摆脱不了一个根深蒂固的习惯——她完全痴迷于照片墙（Instagram），根本停不下来。

这款照片与视频分享社交应用于2012年被脸书（Facebook）以10亿美元收购，吸引了尹在内的1.5亿用户，占据了他们的注意力和思绪¹。

脸书的这笔收购，恰恰印证了形成习惯的技术所蕴含的日益强大的力量，以及它能创造的巨大商业价值。

当然，照片墙的收购价受多种因素影响，其中就包括传闻中多家公司的竞价²。但本质上，照片墙是一个典型案例：创始团队既精通技术，又深谙心理学，他们推出的这款产品能让用户形成习惯，进而成为日常生活的一部分³。

尹并未意识到自己已经“上瘾”，但她承认每天都会用这款应用拍摄并发布数十张照片。“就是觉得好玩，”她一边浏览最新拍摄的、经过滤镜处理、带有20世纪70年代复古风格的氛围感快照，一边说道，“我没觉得这是个问题。只要看到有趣的东西，我就想用它记录下来，生怕错过。”

是什么让尹养成了使用照片墙的习惯？这款看似简单的应用，为何会成为她生活中如此重要的一部分？正如我们即将了解到的，像尹这样的习惯是日积月累形成的，但触发这一系列行为、最终养成习惯的，始终是“触发”机制。

## 习惯并非凭空创造，而是逐步构建
习惯就像珍珠。牡蛎会分泌一种名为珍珠质的物质，一层一层包裹异物，历经数年最终形成光滑的珍珠。但珍珠质为何会开始凝结成珍珠呢？一颗微小的刺激物，比如一粒沙或一只不受欢迎的寄生虫，会触发牡蛎的身体系统，开始用一层层闪亮的物质包裹这个入侵者。

同样，新习惯的养成也需要一个基础。触发机制，就是持续改变行为的基石。

不妨回想一下你自己的生活：今天早上是什么叫醒你的？是什么让你刷牙？又是什么让你翻开了这本书？

触发机制可能是像早晨闹钟这样明显的提示，也可能是更微妙、甚至潜意识的信号，但它们都能有效地影响我们的日常行为。触发是行为的催化剂，就像牡蛎中催生珍珠的沙粒。无论我们是否意识到，触发都会促使我们采取行动。

触发分为两种类型：外部触发和内部触发。

### 外部触发
形成习惯的技术，首先会通过行动召唤来提示用户，从而改变他们的行为。这种感官刺激会通过我们周围环境中的各种事物传递。

外部触发中蕴含着明确的信息，告诉用户接下来该做什么。

外部触发会清晰地告知用户下一步的行动，通常会把期望的行为明确呈现出来。比如，看看图2中这台可口可乐自动售货机，你能发现哪些外部触发？

仔细观察图中面带微笑的男士，他正递给你一瓶清爽的可乐。图片下方的“口渴了？”字样，既传达了男士的疑问，也提示着你接下来该做的事——投币、选饮料。

在网络世界中，外部触发可能是一个醒目的按钮，比如图3中来自美英特（Mint.com）的邮件里，那个大大的“登录美英特”按钮。同样，用户读完邮件后，会得到明确的行动指示：点击那个大按钮。

（图2：可口可乐自动售货机，上面有“口渴了？”的字样和递饮料的男士图案）

注意到美英特的邮件中，期望的行动多么突出、明确了吗？这家公司本可以在邮件中加入其他触发提示，比如查看银行余额、浏览信用卡优惠或设定财务目标，但这是一封重要的账户提醒邮件，因此美英特将可操作的选项简化为一个：登录账户查看并处理问题。

（图3：美英特的账户提醒邮件，内容为“账户提醒：别错过交易，立即处理你的美英特账户”，下方有“登录美英特”的按钮）

选择越多，用户就需要权衡更多选项。过多的选择或不相关的选项会导致用户犹豫、困惑，甚至放弃操作⁴。减少采取下一步行动所需的思考，能提高用户下意识完成期望行为的概率。这一点我们将在下一章进一步探讨。

可口可乐自动售货机和美英特的邮件，都是明确的外部触发案例。但外部触发也能含蓄地传达期望用户采取的行动。比如，我们都知道网站链接是用来点击的，应用图标是用来点击的。这些常见的视觉触发，唯一的目的就是提示用户行动。作为界面设计中被广泛接受的元素，这些行动召唤无需告知人们如何使用——信息已蕴含其中。

#### 外部触发的类型
企业可以利用四种外部触发，促使用户完成期望的行为：
1. 付费触发
广告、搜索引擎营销等付费渠道，是吸引用户注意力并促使他们行动的常用方式。付费触发可能有效，但维持用户回访的成本很高。善于打造习惯形成型产品的公司，通常不会长期依赖付费触发，甚至完全不依赖。试想，如果脸书或推特需要通过投放广告来吸引用户回访，这些公司很快就会陷入财务困境。

由于付费回访对大多数商业模式来说难以持续，企业通常会用付费触发获取新用户，再通过其他触发方式召回他们。

2. 赢得触发
赢得触发无法直接购买，本质上是免费的，但往往需要投入时间进行公关活动。正面的媒体报道、热门的病毒式视频、应用商店的推荐位，都是吸引注意力的有效方式。企业可能会误以为，相关的下载量或销售额激增就意味着长期成功，但赢得触发带来的关注度往往是短暂的。

要让赢得触发持续带来新用户，企业必须让产品始终保持曝光度——这是一项困难且难以预测的任务。

3. 关系触发
一个人向他人推荐产品或服务，是非常有效的外部触发。无论是通过电子邀请、脸书的“点赞”，还是传统的口碑传播，来自亲友的推荐，往往是技术推广的关键环节。

关系触发能创造创业者和投资者渴望的病毒式爆发增长。有时，关系触发之所以能推动增长，是因为人们乐于分享优质的体验。

比如，20世纪90年代末贝宝（PayPal）的病毒式成功，就很难被超越⁵。贝宝深知，一旦账户持有人开始在线上向其他用户转账，就会意识到这项服务的巨大价值。“有人给你转账了”这一诱惑，是吸引用户注册的强大动力，而贝宝的增长之所以能迅速蔓延，正是因为它既具备病毒式传播的特性，又切实有用。

遗憾的是，有些企业会通过所谓的“黑暗模式”，不道德地利用病毒循环和关系触发：设计师故意诱导用户邀请好友，或向他们的社交网络群发信息。这种做法可能会带来短期增长，但会损害用户的好感和信任。当用户发现自己被欺骗时，就会发泄不满并停止使用产品。

合理运用关系触发，需要建立一个积极参与的用户群体，让他们愿意主动分享产品的优势。

4. 自有触发
自有触发会在用户的环境中占据一席之地，持续出现在日常生活中，而最终是否允许这些触发存在，取决于用户自身。

比如，用户手机屏幕上的应用图标、订阅的电子邮件通讯、应用更新通知，只有在用户允许的情况下才会出现。只要用户同意接收触发，设置触发的公司就获得了一部分用户的注意力。

只有当用户注册账户、提交电子邮件地址、安装应用、订阅通讯，或通过其他方式表示愿意继续接收信息时，企业才能设置自有触发。

付费触发、赢得触发和关系触发主要用于获取新用户，而自有触发则会促使用户重复使用产品，直到形成习惯。如果没有自有触发，没有用户默许企业进入他们的注意力空间，就很难频繁地提示用户，进而改变他们的行为。

但外部触发只是第一步。所有外部触发的最终目标，都是推动用户进入并完成“钩子模型”的循环，经过多次循环后，用户不再需要外部触发的提示。

当用户养成习惯后，触发他们行动的，就变成了另一种类型：内部触发。

### 内部触发
当产品与用户的某个想法、情绪或已有的日常习惯紧密关联时，就会利用内部触发。与外部触发不同——外部触发通过闹钟、“立即登录”按钮等感官刺激发挥作用——内部触发是看不见、摸不着、听不到的。

内部触发会在用户的脑海中自动浮现。将产品与内部触发关联，是消费级技术追求的最高境界。

对于痴迷照片墙的尹来说，这款她最爱的照片应用，通过反复的条件反射训练，让她对内部触发产生了可预测的反应。久而久之，尹“记录身边事物”的需求，与她随身携带的手机里的这款应用，形成了紧密的联系。

情绪，尤其是负面情绪，是强大的内部触发，会极大地影响我们的日常行为。无聊、孤独、沮丧、困惑、犹豫不决等感受，往往会带来轻微的不适或烦躁，进而促使我们下意识地采取行动来缓解这种负面情绪。比如，尹常常在担心某个特别的瞬间会永远消失时，打开照片墙。

这种不适的程度可能相对轻微——或许她的担忧甚至没有被意识到——但这正是关键所在。我们的生活中充满了各种微小的压力源，而我们往往没有意识到自己对这些烦心事的习惯性反应。

积极情绪也能成为内部触发，甚至这些积极情绪本身，也是为了满足某种潜在的需求而产生的。毕竟，我们使用产品是为了解决问题。想要获得娱乐，本质上是为了缓解无聊；想要分享好消息，本质上是为了建立和维持社交联系。

作为产品设计师，我们的目标是解决这些问题、消除不适——也就是满足用户的需求。如果用户发现某款产品能缓解他们的痛苦，久而久之就会对这款产品产生强烈的正面关联。持续使用后，产品与满足用户需求的关联，会像牡蛎中的珍珠质一样，一层一层加深。

渐渐地，这些关联会固化为习惯：当用户感受到某种内部触发时，就会自然而然地想到你的产品。

密苏里科技大学的一项研究，展示了技术解决方案如何提供频繁的心理慰藉⁶。2011年，216名本科生自愿参与了一项研究，他们的网络活动被匿名追踪。在整个学年里，研究人员统计了这些学生使用网络的频率和具体行为。

研究结束时，研究人员将匿名数据与那些因抑郁症状前往学校健康服务中心就诊的学生进行了对比。“我们发现了一些与抑郁相关的网络使用特征，”该研究的作者之一斯里拉姆·切拉潘（Sriram Chellappan）写道⁷，“比如，有抑郁症状的参与者往往会频繁查看电子邮件……此外，他们还会更频繁地观看视频、玩游戏和聊天。”

这项研究表明，患有抑郁症状的人使用网络的频率更高。原因何在？一种假设是，抑郁症患者比普通人更频繁地经历负面情绪，他们会通过使用技术来改善心情，寻求慰藉。

或许你可以想一想自己那些由情绪触发的行为：当感受到内部触发时，你会怎么做？

感到无聊时，很多人会寻求刺激，点开耸人听闻的新闻标题；压力过大时，会寻求平静，或许会在拼趣（Pinterest）等网站上找到慰藉；感到孤独时，脸书和推特等平台能提供即时的社交连接。

为了缓解不确定性带来的焦虑，只需点击一下就能使用谷歌搜索；电子邮件或许是所有形成习惯的技术中最典型的代表，它能解决我们日常的诸多烦恼——比如通过查看是否有人需要自己来确认自身的重要性（甚至存在价值），或是在平淡的生活中寻找一丝乐趣。

一旦养成习惯，使用这些产品往往不需要明确的行动召唤。相反，它们依赖于我们对那些能引发期望行为的感受，做出下意识的反应。与内部触发相关联的产品，能为用户提供即时的慰藉。一旦技术在用户心中建立了“这款产品是首选解决方案”的关联，用户就会主动回访，不再需要外部触发的提示。

对于内部触发而言，下一步该做什么的信息，已经以习得关联的形式，存储在用户的记忆中。

然而，产品与内部触发之间的关联并非一蹴而就。通常需要数周甚至数月的频繁使用，内部触发才能与提示建立起牢固的联系。新习惯由外部触发引发，但正是与内部触发的关联，让用户欲罢不能。

就像尹说的：“只要看到有趣的东西，我就会用它（照片墙）记录。”通过巧妙地引导用户从外部触发过渡到内部触发，照片墙在人们的生活中构建了一种持久的习惯。每当遇到值得珍藏的瞬间，尹的脑海中就会产生一种需求，而对她来说，即时的解决方案就是照片墙。尹不再需要外部刺激来促使她使用这款应用——内部触发会自然而然地出现。

## 为触发机制而设计
成功打造习惯形成型产品的关键，在于找到用户的某种情绪，并通过产品缓解这种情绪。要做到这一点，产品设计师必须了解用户的内部触发——也就是他们想要解决的痛点。但仅仅通过问卷调查，很难真正了解用户的内部触发，还需要深入挖掘他们的真实感受。

打造习惯形成型产品的终极目标，是通过建立关联，让用户将企业的产品或服务视为缓解痛苦的来源，从而解决他们的痛点。

首先，企业必须从情绪层面，而非产品功能层面，找出用户特定的困扰或痛点。作为设计师，该如何挖掘用户痛苦的根源呢？最好的起点，是研究那些成功的习惯形成型产品背后的驱动因素——不是为了抄袭，而是为了理解它们如何解决用户的问题。这样做能帮助你更深入地洞察消费者的心理，了解人类共通的需求和渴望。

正如博客（Blogger）和推特的联合创始人埃文·威廉姆斯（Evan Williams）所说，互联网是“一台旨在满足人们需求的巨大机器”⁸。他还补充道：“我们常常认为互联网能让你做以前做不到的事……但实际上，人们只是想做他们一直以来都想做的事。”

这些共通的需求是永恒且普遍的。但通过询问用户来挖掘这些需求，往往效果不佳——因为用户自己也不知道是什么情绪在驱动他们。人们很少会从这个角度思考问题。你会发现，用户口中所说的偏好，往往与他们实际的行为大相径庭。

正如《足够的研究》（Just Enough Research）一书的作者埃里卡·霍尔（Erika Hall）所写：“当研究聚焦于人们实际的行为（比如看猫咪视频），而非他们希望自己做的事（比如制作影院级别的家庭电影）时，实际上会拓展更多可能性。”发现这种差异，就能找到机会。人们发送短信的真正原因是什么？他们拍照是为了什么？看电视或体育比赛在他们的生活中扮演着什么角色？不妨问问自己，这些习惯解决了什么痛苦，用户在采取这些行动之前可能会有什么样的感受。

用户希望通过你的解决方案实现什么目标？他们会在何时何地使用它？哪些情绪会影响他们的使用，并触发他们采取行动？

推特和斯奎尔（Square）的联合创始人杰克·多西（Jack Dorsey），分享了他的公司如何回答这些重要问题：“如果你想打造一款与用户息息相关的产品，就需要换位思考，站在他们的角度编写一个故事。因此，我们会花大量时间撰写所谓的‘用户叙事’。”¹⁰

多西进一步描述了他如何真正理解用户：“比如，用户身处芝加哥市中心，走进一家咖啡店……这就是他们即将经历的场景。这种叙事读起来就像一出戏剧，非常生动。如果能把这个故事写好，那么产品的优先级排序、设计、以及各个部门（从工程师、运营、客服，到设计师、业务部门）之间的协作，都会自然而然地推进。因为你可以不断完善这个故事，公司里的每个人都能理解。”

多西认为，清晰地描述用户——包括他们的欲望、情绪、使用产品的场景——是打造合适解决方案的关键。除了多西提到的用户叙事，客户开发¹¹、可用性研究、共情图¹²等工具，也能帮助你了解潜在用户。

其中一种方法是，不断追问“为什么”，直到触及情绪层面，通常问五次就能找到根源。这种方法源自丰田生产系统，被大野耐一（Taiichi Ohno）称为“五个为什么分析法”。大野耐一写道：“这是丰田科学方法的基础……通过重复五次‘为什么’，就能看清问题的本质和解决方案。”¹³

想要弄明白人们为什么会使用习惯形成型产品，内部触发是根本原因，而“为什么”这个问题，能帮助我们直击核心。

比如，假设我们第一次开发电子邮件这种全新的技术，目标用户是一位名叫朱莉的忙碌的中层管理者。我们已经为用户朱莉撰写了详细的叙事，现在可以通过以下一系列“为什么”来寻找答案：

1. 为什么朱莉想使用电子邮件？
答案：为了发送和接收信息。

2. 为什么她想做这件事？
答案：因为她想快速分享和获取信息。

3. 为什么她想快速分享和获取信息？
答案：为了了解同事、朋友和家人的近况。

4. 为什么她需要了解这些？
答案：为了知道是否有人需要她。

5. 为什么她在乎这一点？
答案：她害怕被排除在圈子之外。

现在我们找到了关键！恐惧是一种强大的内部触发，我们可以设计解决方案来缓解朱莉的这种恐惧。当然，如果我们选择不同的用户画像、改变叙事内容，或者在追问过程中给出不同的假设答案，可能会得出其他结论。只有准确理解用户的潜在需求，才能明确产品的要求。

既然我们已经了解了用户的痛点，接下来就可以测试产品，看看它是否能解决这个问题。

## 拆解照片墙的触发机制
照片墙之所以能取得成功，吸引数百万用户几乎每天回访，很大程度上得益于其团队对用户触发机制的深刻理解。对于尹这样的用户来说，照片墙是情感和灵感的港湾，是用像素保存的虚拟回忆录。

尹对这款应用的习惯性使用，始于一个外部触发——朋友的推荐。经过数周的反复使用，她成为了忠实用户。

每次尹拍摄照片后，都会分享到脸书和推特上。回想一下你第一次看到照片墙风格的照片时的感受：它是否吸引了你的注意力？是否让你感到好奇？是否促使你采取行动？

这些照片本身就是一种关系型外部触发，既能提高产品的曝光度，又能提示其他人下载和使用这款应用。但照片墙在脸书和推特上分享的照片，并非吸引新用户的唯一外部触发。还有人通过媒体报道、博主推荐，或是苹果应用商店对照片墙的推荐——这些都属于赢得型外部触发。

应用安装后，照片墙就会受益于自有外部触发：用户手机屏幕上的应用图标，以及关于好友动态的推送通知，都会召唤用户回访。

通过反复使用，照片墙与内部触发建立了牢固的关联。曾经只是偶尔用来消遣的应用，变成了许多用户一天中不可或缺的习惯。

正是“害怕错过特殊瞬间”这种情绪，引发了一丝紧张感。这种负面情绪作为内部触发，会促使照片墙用户打开应用，通过拍照来缓解这种不适。随着用户持续使用，新的内部触发也会逐渐形成。

但照片墙不仅仅是相机的替代品，它更是一个社交网络。这款应用通过连接用户、分享照片、轻松互动，帮助用户缓解无聊¹⁴。

和许多社交网站一样，照片墙还能缓解一种日益凸显的痛点——“错失恐惧”（FOMO）。对照片墙而言，与内部触发的关联，为新习惯的形成奠定了基础。

接下来，我们需要了解如何利用“钩子模型”的下一步，将用户的问题与你的解决方案联系起来。下一章，我们将探讨如何引导用户从触发过渡到行动，这是建立新习惯的关键。

## 要点回顾与分享
- 触发是“钩子模型”的第一步，它会提示用户采取行动。
- 触发分为两种类型：外部触发和内部触发。
- 外部触发通过在用户环境中传递信息，告知用户下一步该做什么。
- 内部触发通过存储在用户记忆中的关联，告知用户下一步该做什么。
- 负面情绪常常成为内部触发。
- 想要打造习惯形成型产品，开发者需要了解哪些用户情绪可能与内部触发相关联，并知道如何利用外部触发促使用户采取行动。
