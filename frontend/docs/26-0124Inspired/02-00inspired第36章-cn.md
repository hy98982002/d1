# 第36章 可用性与美感：二者缺一不可
我想大多数人都会认同，就大多数公司的实践而言，网站设计整体仍处于初级阶段。尽管存在一些值得关注的例外，但许多网站——即便是大型企业的网站——往往要么使用难度极高，要么完全缺乏美感，甚至两者兼具。我对为何如此多的网站设计糟糕透顶有一些看法，也思考过随着我们在生活中与网络的互动日益频繁，该如何改善这一现状。

我早就注意到，太多公司在用户体验上投入的时间和资源远远不足。但让我更难解释的是，那些确实投入了时间和资源在用户体验上的公司，为何仍常常做出糟糕的网站。

有两种极端情况尤其让我觉得耐人寻味。一方面，众多图形/视觉设计公司的网站美观且富有艺术性，却难以阅读、结构混乱；另一方面，许多交互设计公司的网站使用便捷、导航清晰、能轻松找到所需信息，却枯燥乏味、设计简陋、毫无吸引力。

我认为这两种情况恰好说明，交互设计和视觉设计是截然不同的两门学科。要打造一个既好用又具吸引力的网站，设计团队必须同时具备这两种技能。有些团队十分幸运，能拥有兼具这两种设计才能的设计师，但在很多情况下，他们只是想当然地认为，既然雇了“设计师”，这个人就应该能胜任两者——但事实并非如此。

更糟糕却也最常见的情况是，公司既没有这两种类型的设计师，还指望产品经理或用户界面工程师来设计网站。遗憾的是，当我与企业级公司交流时，发现这种情况依然很普遍；而与消费类创业公司沟通时，他们通常会拥有其中一种类型的设计师。

许多团队认为，产品或网站的视觉设计并非真正重要。他们声称，关键在于功能和价值主张，而诸如美观的颜色、字体、图标和布局之类的东西，都只是不必要的表面装饰。我强烈反对这种观点，见过的产品越多，我就越坚信：其一，情感在打造具有吸引力的产品中扮演着重要角色；其二，视觉设计直接影响着这种情感的产生。

向用户展示功能完全相同的产品——一个采用线框图设计，另一个采用优质视觉设计——用户的整体反应可能会截然不同。

就像产品管理和产品营销是不同职能，需要不同的培训和技能一样，交互设计和视觉设计也是不同职能，同样需要不同的培训和技能。

在此我略作简化——尚未讨论产品经理或可用性工程师在开发既好用又令人愉悦的网站中所扮演的关键角色。而且，如果网站运行缓慢、漏洞百出，或是充斥着广告，那么这些因素当然也会对用户体验产生重大负面影响。

但从根本上来说，我认为要提供良好的用户体验，必须同时具备交互设计和视觉设计的技能，这些设计师需要与产品经理密切合作，共同定义产品——包括产品的功能和用户体验。
