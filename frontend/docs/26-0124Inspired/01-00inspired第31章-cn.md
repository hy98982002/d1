# 第31章 来自苹果的启示：一家与众不同的硬件公司
我得先坦白一点：我是苹果的忠实粉丝。我认为，在过去25年里，苹果打造出了业内一些最优秀的科技产品。自从1983年丽萨电脑（我把它视作麦金塔电脑的原型）向公众发布以来，我就一直是这家公司的拥趸。在我看来，史蒂夫·乔布斯是有史以来最出色的产品经理之一。

最近，苹果手机（iPhone）亮相登场，再次重新定义了整个行业。但当我和人们谈论这款产品以及苹果公司时，我惊讶地发现，对于苹果成功的原因，大家的看法五花八门。

我非常不认同那些将苹果的成功归功于营销能力的观点——尽管我承认他们的营销做得相当不错。

为了说明这一点，我们不妨来看看iPhone。我不想过多纠结于它的具体参数，而是想探讨一下，为什么苹果总能持续重新定义大型消费市场——无论是个人电脑、数字音乐播放器，还是手机领域。

我们能从苹果身上学到很多，但对我而言，最核心的有三个启示：

## 1. 硬件服务于软件
与几乎所有其他硬件公司不同，苹果深知硬件的作用是为软件服务，而非相反。软件需要明确用户希望手机具备哪些功能，因此像多点触控显示屏、加速度计和距离传感器等硬件技术应运而生，正是为了实现这些功能。每一项技术的存在都有其明确的目的。话虽如此，尽管硬件和软件技术确实令人赞叹，但苹果明白，一旦越过早期采用者这个群体，人们真正在意的就不再是这些技术本身了。这就引出了下一点……

## 2. 软件服务于用户体验
如今，几乎所有消费类公司都在口头上标榜用户体验的重要性，但苹果是真正将其落到实处的。易用性、交互设计、视觉设计、工业设计——这些都处于公司优先级的核心位置，而这一点在产品上体现得淋漓尽致。iPhone的研发或许耗时两年半，但团队始终清楚，一切的核心都是用户体验，为了打造卓越的体验，他们愿意克服重重困难。此外，公司上下各个层级都拥有足够的人才和毅力，确保这一目标能够实现。相比之下，有一个广为人知的例子：微软曾试图在Vista系统中进行一项微小却早该完成的用户体验改进，但过程却举步维艰。然而，即便用户体验至关重要，苹果也明白……

## 3. 用户体验服务于情感
如果说苹果作为一家科技公司有什么独门绝技，我认为正是这一点：他们比任何人都更清楚情感在促使消费者渴望、购买并热爱一款产品时所扮演的角色。他们懂得如何打造能够触动消费者这些情感的产品。人们对iPhone趋之若鹜。一部手机售价400美元？根本不成问题，因为消费者并不是在将iPhone与摩托罗拉刀锋手机（Razr）或奔迈手机（Treo）做比较——它完全处于另一个层级。你不妨在机场休息室观察一下：人们对待个人电脑（PC）就像对待租赁来的汽车一样随意，但呵护麦金塔电脑（Mac）却如同对待自己的梦想座驾。而且，如果你足够大胆，不妨试试从一个青少年手中拿走他的苹果音乐播放器（iPod）。

市面上有超过一百种不同的手机，但很难找到真正热爱自己手机的人。人们早已厌倦了数十年来毫无改进的语音信箱系统、互不兼容的通讯录、难用至极的网页浏览器以及蹩脚的电子邮件功能。而苹果推出的产品，直接回应了这些未被满足的需求。数字音乐播放器领域也曾发生过同样的事情。

令我感到惊讶的是，如此少的公司能领悟到这些核心要点。即便是那些试图模仿苹果的公司，也往往只想到复制功能，却忽略了真正重要的东西。
